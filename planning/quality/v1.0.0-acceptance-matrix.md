# v1.0.0 Acceptance Matrix (reset sync)

Defined requirement scope: `R-01`..`R-14` from `planning/system/traceability-matrix-v1.0.0.md`.

## Stability

- Req: `R-01`, `R-02`, `R-09`
- Criteria:
  - recoverable GPU/PTY failures do not drop active shell session;
  - fallback behavior is deterministic and bounded;
  - no silent degrade path.
- Evidence:
  - manual scenarios in `planning/operations/v1.0.0-manual-test-plan.md`.

## AI CLI Compatibility

- Req: `R-07`, `R-10`, `R-13`
- Criteria:
  - stable long-running behavior for Claude Code/Codex/Gemini CLI workloads;
  - deterministic startup and prompt readiness;
  - stable copy/paste and output behavior in sustained sessions.
- Evidence:
  - compatibility scenarios in `planning/operations/v1.0.0-manual-test-plan.md`;
  - `scripts/mvp/*` emits `MVP_GATE_RESULT ... status=pass ...` for Claude/Codex/Gemini.

## Speed and Latency

- Req: `R-03`, `R-04`, `R-08`
- Criteria:
  - monitor-driven cadence is active;
  - monitor transfer re-sync works without session restart;
  - memory growth is bounded under long-run stress;
  - no hardcoded FPS in primary runtime path.
- Evidence:
  - pacing and stress scenarios in `planning/operations/v1.0.0-manual-test-plan.md`.

## UX and Scope

- Req: `R-05`, `R-11`, `R-12`
- Criteria:
  - settings changes are available via command palette;
  - single-window baseline is maintained and explicit in harness output (`single_window_required=1`, `single_window_enforced=yes`);
  - release remains manual-only with explicit checklist.
- Evidence:
  - `planning/settings/settings_palette.md`
  - `planning/operations/v1.0.0-release-pack.md`
  - `scripts/mvp/*` logs with `MVP_RESULT ... windows=1 ... release_governance=manual-only`.

## Architecture and Dependency Governance

- Req: `R-06`, `R-14`
- Criteria:
  - VSA dependency flow remains enforceable: `app -> features -> services -> core`;
  - `foundation` integrations are consumed through explicit API contracts/adapters;
  - self-authored-first runtime policy remains enforced, and dependency usage is justified with explicit boundary contracts.
- Evidence:
  - `planning/operations/v1.0.0-start-readiness-index.md`
  - `planning/system/dependency-evidence-context7-v1.0.0.md`
