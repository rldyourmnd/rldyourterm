## 3.1) Implementation status addendum (2026-03-04)

- Workspace crate map: `app`, `core`, `services`, `ui`, `foundation`, `foundation-platform`, `features/*`.
- `foundation-platform` currently implemented как единый crate с модулями `pty/window/clipboard` (не split-пакеты `linux|macos|windows` на уровне структуры crate’ов).
- Runtime wiring status:
  - PTY adapter: wired.
  - clipboard adapter: wired in app runtime.
  - window adapter: wired in app runtime (`G-010` closed).

## 4) Нулевая противоречивость (актуальная)

- Нет конфликтов между hard constraints и детализацией:
  - single-window, no multiplexer,
  - три режима рендера (cpu/gpu/auto),
  - fallback gpu->cpu,
  - monitor-driven frame cadence (без hardcoded fps target в primary UX),
  - in-terminal settings как primary UX,
  - bounded memory и scrollback cap 50_000.
- No silent fallback: обязательная фиксация `RenderModeTransition` во всех fallback сценариях.
- foundation остается только адаптационным слоем через API traits.
