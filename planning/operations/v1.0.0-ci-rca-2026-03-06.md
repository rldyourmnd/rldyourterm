# v1.0.0 CI RCA (2026-03-06)

Date: 2026-03-06  
Repository: `rldyourmnd/rldyourterm`  
Reference run: GitHub Actions `CI` run `22742362622` (failed), `Scorecard` run `22742362618` (failed)

## 1) Failure Summary

1. `Cargo Deny` failed.
2. `Scorecard` failed in `ci.yml` action setup.
3. Standalone `Scorecard` workflow failed on publish permissions.
4. `dependency-review` and `labeler` were skipped on push events by design (`pull_request`-only jobs).

## 2) Root Causes

### RC-1: Cargo deny policy mismatch on internal workspace dependencies

- `deny.toml` had `wildcards = "deny"`.
- Multiple internal crates used `{ path = "..." }` without explicit version, interpreted as wildcard requirements.
- Result: `error[wildcard]` across workspace members.

### RC-2: License allowlist gap

- Transitive dependency graph included `BSL-1.0` (`arboard -> clipboard-win -> error-code` path on Windows target).
- `deny.toml` did not allow `BSL-1.0`, causing hard failure.

### RC-3: Scorecard action reference and publish-path contract violations

- `ci.yml` used invalid/unstable Scorecard action reference previously, then mixed Scorecard publish-path execution in a general CI workflow.
- Standalone `scorecard.yml` missed `id-token: write` required for `publish_results: true`.

### RC-4: Latent workflow consistency issues

- `release.yml` tag pattern used regex-like syntax under `on.push.tags` (GitHub Actions expects glob patterns).
- `release.yml` packaging step archived `rldyourterm`, while produced binary is `rldyourterm-app`.
- `codeql.yml` missed Linux system deps used in the primary Rust CI path.
- `labeler` write-permission path on fork PRs is inherently non-deterministic without an explicit same-repo guard.

## 3) Corrective Actions Implemented

### Cargo / dependency governance

1. Internal crate dependencies centralized in workspace root:
   - `[workspace.dependencies]` now defines `rldyourterm-*` entries with explicit `{ version = "0.1.0", path = "..." }`.
2. Member manifests switched to `dep.workspace = true` for internal crates.
3. `deny.toml` updated:
   - allow `BSL-1.0`,
   - remove unmatched `MPL-2.0`,
   - set `multiple-versions = "allow"` for current cross-platform graphics/input stack coexistence.

### CI / workflow hardening

1. `ci.yml`:
   - added workflow concurrency cancelation for stale runs,
   - changed MSRV action ref from floating `@master` to stable ref,
   - made `labeler` fork-safe with same-repo condition and updated to `actions/labeler@v6.0.1`,
   - removed inlined Scorecard job; Scorecard now isolated to dedicated workflow.
2. `scorecard.yml`:
   - added `workflow_dispatch`,
   - added required permissions (`actions: read`, `id-token: write`, `security-events: write`),
   - pinned `ossf/scorecard-action@v2.4.3`,
   - added SARIF upload step.
3. `codeql.yml`:
   - updated action refs to `github/codeql-action@v4`,
   - aligned Linux system deps with CI build path.
4. `release.yml`:
   - fixed tag trigger to glob pattern (`"v*.*.*"`),
   - added `workflow_dispatch`,
   - pinned `cargo-bins/cargo-binstall@v1.17.6`,
   - fixed packaged binary name to `rldyourterm-app`.
5. `semantic.yml`:
   - updated to `amannn/action-semantic-pull-request@v6.1.1`,
   - added `ready_for_review` PR event.
