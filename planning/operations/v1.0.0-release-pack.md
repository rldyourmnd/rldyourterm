## 3) MVP Compatibility Lock (Claude/Codex/Gemini)

Required execution (with transcript capture):

```bash
bash scripts/mvp/scenario_claude.sh 4 | tee "scripts/mvp/output/gate-claude-$(date +%Y%m%d-%H%M%S).log"
bash scripts/mvp/scenario_codex.sh 4 | tee "scripts/mvp/output/gate-codex-$(date +%Y%m%d-%H%M%S).log"
bash scripts/mvp/scenario_gemini.sh 4 | tee "scripts/mvp/output/gate-gemini-$(date +%Y%m%d-%H%M%S).log"
```

Alternative aggregate gate:

```bash
bash scripts/mvp/run_matrix.sh 3 | tee "scripts/mvp/output/matrix-$(date +%Y%m%d-%H%M%S).log"
```

Evidence requirements:
- one profile runtime log per executed profile under `scripts/mvp/output/` (`<profile>-<timestamp>.log`),
- each profile log has `MVP_HARNESS` with `single_window_required=1` and `release_governance=manual-only`,
- each profile log has `MVP_HARNESS_CMD` with `--window-count 1`,
- each profile log has `MVP_STEP ... command=single-window:1 ...`,
- each profile log has `MVP_RESULT`,
- each `MVP_RESULT` contains `windows=1`,
- each `MVP_RESULT` contains `single_window_required=1` and `single_window_enforced=yes`,
- each `MVP_RESULT` contains `release_governance=manual-only`,
- each `MVP_RESULT` has acceptable runtime state (`running` or `degraded`),
- each scenario transcript contains `MVP_GATE_RESULT ... status=pass ...`,
- matrix transcript contains `MVP_MATRIX_RESULT ... status=pass ...` when matrix mode is used.
