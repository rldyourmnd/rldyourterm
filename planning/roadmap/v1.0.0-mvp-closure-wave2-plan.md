# v1.0.0 MVP Closure Wave-2 Plan (10 Parallel Agents)

Date: 2026-03-03
Status: Ready for execution
Objective: move from runtime skeleton to MVP-closure candidate aligned with hard priorities:
1. Stability (crash-intolerant)
2. AI CLI compatibility (Claude Code, Codex, Gemini CLI)
3. Ultra-low latency

## Context7-backed dependency baseline
- `portable-pty`: `/websites/rs_portable-pty` (openpty/spawn/reader/writer/resize/wait/kill)
- `winit`: `/websites/rs_winit_winit` (window events + monitor refresh API)
- `wgpu`: `/websites/rs_wgpu` (SurfaceConfiguration + SurfaceError policy)

## Wave-2 Workstreams

1. Agent01 Core safety hardening
- Scope: `crates/core/src/{events.rs,parser.rs,state.rs}`
- Deliverables:
  - bounded input feed safeguards,
  - explicit non-fatal ingest/degrade events,
  - deterministic tests for large/malformed payload handling.
- Req: `R-01`, `R-08`

2. Agent02 Foundation contract completion
- Scope: `crates/foundation/src/{lib.rs,error.rs,diagnostics.rs,api/*}`
- Deliverables:
  - contract-level clarity for PTY/window/diagnostics boundaries,
  - typed diagnostics primitives without placeholder models,
  - consistent error/recoverability mapping.
- Req: `R-06`, `R-09`, `R-10`

3. Agent03 PTY adapter robustness
- Scope: `crates/foundation-platform/src/pty.rs`
- Deliverables:
  - stronger lifecycle handling for closed/EOF/kill/wait paths,
  - deterministic writer lease behavior,
  - non-crashing read/write pump semantics.
- Req: `R-01`, `R-09`

4. Agent04 Window+clipboard adapter hardening
- Scope: `crates/foundation-platform/src/{window.rs,clipboard.rs}`
- Deliverables:
  - monitor-transfer timing re-sync signal reliability,
  - deterministic fallback order for monitor timing,
  - safer clipboard degraded behavior.
- Req: `R-03`, `R-04`

5. Agent05 Session service reliability layer
- Scope: `crates/services/src/{session.rs,error.rs}`
- Deliverables:
  - explicit policy semantics for recoverable/fatal boundaries,
  - deterministic handling of PTY boundary failures,
  - extended state-machine tests for no-drop behavior.
- Req: `R-01`, `R-07`, `R-09`

6. Agent06 Render control no-silent-fallback enforcement
- Scope: `crates/services/src/{render_mode.rs,render_pacing.rs}`
- Deliverables:
  - stronger fallback transition metadata,
  - monitor-driven cadence re-sync invariants,
  - tests proving no silent mode switch path.
- Req: `R-02`, `R-03`, `R-04`

7. Agent07 CPU renderer runtime stats + determinism
- Scope: `crates/features/render_cpu/src/lib.rs`

8. Agent08 GPU renderer runtime state policy

9. Agent09 Settings/shell/diagnostics feature maturity

## Integration policy
- Parallel implementation is allowed, but cross-agent API breakage is forbidden.
- Additive changes preferred; if interface must change, provide backward-compatible path.
- Coordinator performs final API alignment and workspace-wide verification.

## Done gate for Wave-2
- all agents exit `0`;
- workspace compiles and tests pass;
- manual/compatibility scripts and docs are runnable and synchronized.
