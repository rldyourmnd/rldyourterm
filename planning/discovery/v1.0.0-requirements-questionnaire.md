# v1.0.0 Requirements Questionnaire (locked)

Дата: 2026-03-02
Статус: CLOSED FOR v1.0 (answers locked in `v1.0.0-answer-lock.md`)

## Product and User

1) Кто основной пользователь?
- Визионер продукта и AI CLI power-user.

2) Какие задачи являются базовыми?
- Длительные interactive/manual + AI automation workflows.

## Stability and Runtime Safety

3) Какой SLA по падениям?
- Crash-intolerant target, recoverable faults cannot drop shell session.

4) Какой fallback policy?
- Bounded retries + deterministic `gpu -> cpu` fallback with explicit notification/events.

5) Что по памяти?
- Bounded growth + scrollback cap 50_000.

## Performance and Render

6) Как задаётся cadence?
- Monitor-driven cadence by system refresh-rate, no hardcoded FPS in primary path.

7) Какие render modes обязательны?
- `cpu`, `gpu`, `auto`.

## Shell and AI Compatibility

8) Какие shell target обязательны?
- `fish + starship` baseline, `zsh` fallback, bash non-primary.

9) Какие AI tools критичны?
- `Claude Code`, `Codex`, `Gemini CLI`.

10) Какие UX-сценарии критичны?
- Prompt readiness, deterministic input/output, stable copy/paste, preserved scrollback/cursor/color state.

## Scope and Platform

11) Multi-window/multiplexer в v1?
- Нет, single-window baseline.

12) Platform scope?
- Ubuntu 22.04/24.04/25.10 + macOS, Windows architecture skeleton only.

## UX and Config

13) Основной UX настроек?
- In-terminal command palette (`Ctrl/Cmd + Shift + P`).

14) Visual baseline?
- Clean performant rendering without heavy visual effects.

## Engineering Policy

15) Self-authored policy?
- Project-owned runtime logic by default, external deps only for integration boundaries.

16) External terminal core usage?
- Forbidden in v1.0.

## Diagnostics and Ops

17) Observability minimum?
- Structured logs + correlation IDs + runtime diagnostics + debug mode.

18) Release process?
- Manual-only evidence-driven process, no CI gate baseline.

19) Release metrics?
- startup readiness, prompt-to-paint p95, copy/paste p95, frame time, crash-free runtime share, memory growth trend.

20) Blocking defects?
- Any crash path, shell continuity break, unsafe fallback path, severe latency regression.

## Post-v1 Reserve

21) Что вынесено за v1?
- multiplexer, multi-window, heavy effects, advanced non-core features.

22) Где финальная фиксация ответов?
- `planning/discovery/v1.0.0-answer-lock.md`.
