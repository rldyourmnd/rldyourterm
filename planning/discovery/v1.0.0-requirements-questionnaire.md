# V1.0.0 Discovery Questionnaire (Final lock)

Этот документ содержит финальные ответы для этапа v1.0.0.

1) Основной пользователь: продуктовый владелец и AI/CLI power-user с упором на визуал и стабильность в долгих сессиях.

2) Типы задач: mix: manual work + AI пайплайны + длительные фоновые и интерактивные сессии.

3) SLA по падениям: минимальные падения; любая GPU ошибка не должна завершать сессию, требуется controlled fallback.

4) Автопереключение: автоматический `gpu -> cpu` с уведомлением и диагностикой.

5) RAM-пороги: явный порог не задаём, оптимизируем через профилирование и cap scrollback/диагностику.

6) FPS: фиксированный порог не задаём; каденс рендера берётся из системной частоты текущего монитора и пересинхронизируется при переносе окна между 60/144Hz без перезапуска.

7) Shell сценарии: `fish + Starship` baseline, fallback `zsh`; Bash — не целевой v1.0 на Linux/macOS.

8) Legacy совместимость: приоритет стабильности базовых сценариев; редкие/экзотические ANSI-расширения — контролируемая деградация.

9) AI-критичные события: prompt latency, copy/paste latency, сохранность cursor/color state, stable scrollback.

10) Scrollback: минимум 50_000 строк, hard cap в v1.0.

11) Multi-window/multi-tab: single-terminal baseline.

12) UI: базовый профиль `cuberpunk`, гибкие профили в backlog.

13) GPU-подход: `wgpu` с платформенной поддержкой (`Vulkan/OpenGL` fallback на Linux, `Metal` на macOS).

14) Текстовые эффекты: только чистый рендер в v1.0, дорогостоящие эффекты перенесены в roadmap.

15) Windows: архитектурная заготовка в foundation, функциональная полнота не входит в v1.0.

16) Наблюдаемость: structured logs, frame timing, memory trend, event-id для GPU/PTY-сбоев.

17) Метрики релиза: startup readiness, prompt-to-paint p95, copy/paste p95, frame time, CPU/GPU usage, crash-free share, memory growth.

18) Обновления: GitHub releases + install script как primary; apt/homebrew как roadmap post-v1.0.

19) Профили производительности: поддержка cpu-only, gpu-only и auto в v1.0 в рамках ручного тест-плана.

20) Blocker: падение старта shell, повторные падения, деградация prompt/цвет/скролл, memory leaks, частые GPU crashes.

21) Roadmap hooks: session recorder, split-screen, advanced diagnostics, и т.д. — post-v1.0.

22) Формат документации: без CI, ручной контроль в markdown с четкими чек-листами и acceptance-критериями.
