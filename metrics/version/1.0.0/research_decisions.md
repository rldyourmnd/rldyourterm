# v1.0.0 Research Decisions

## Исходные требования
- Нужно совместить стабильность длинных сессий, производительность и AI-совместимость.
- Ожидаются Linux (22.04, 24.04, 25.10) и macOS на старте.

## Проверенные технологические решения
- `portable-pty` — как PTY-слой с минимизацией платформенных рисков.
- `winit` — унифицированный event loop для окна и ввода.
- `wgpu` — единый GPU-абстрактный рендер с диагностируемыми error-путями.
- Внутренний parser, grid и сервисы оркестрации реализуются в собственных слоях, а не берутся из чужого terminal-engine.

## Принятые архитектурные рамки
- Не брать multiplexer на v1.0.
- Не полагаться на внешнюю конфиг-ориентированную настройку как primary UX.
- Никакой CI-driven release-контроль в v1.0.
