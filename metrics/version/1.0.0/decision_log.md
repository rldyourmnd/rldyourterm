# v1.0.0 Decision Log

## Scope
Дата: 2026-02-24
Текущий релизный baseline: `1.0.0`.

## Данные решения

- Выбранная архитектура: VSA слоистая модель (`foundation`, `core`, `services`, `features`, `ui`, `app`).
- Модель рендера: два варианта `cpu`, `gpu`, плюс `auto` с автоматическим fallback.
- PTY-слой: не писать собственный PTY; использовать `portable-pty` как единственный базовый PTY абстракционный слой.
- Оконный и event-loop слой: использовать `winit`.
- GPU рендер: использовать `wgpu` как cross-platform backend.
- Frame pacing: monitor-driven cadence от системного refresh-rate без обязательного числового `fps-target` в primary UX.
- UX настроек: в-терминальный command palette как primary path.
- Shell baseline: `fish + starship`, fallback `zsh`.
- Обновления/релиз: без CI, только ручной release-процесс.
- Windows: адаптерная заготовка в `foundation`, функциональная полнота после v1.0.

## Обоснование
Решения выбраны для максимальной стабильности и управляемости отказов: минимизация ядровой зависимости от ОС, явная локализация сбоев на границах адаптеров и контролируемая деградация `gpu -> cpu`.
